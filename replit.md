# Running this project on Replit

This is a single-file C++17 console exercise. Use the **Run eligibility check** console workflow to compile and run `main.cpp`. The workflow rebuilds the program on every run.

To run it from the Shell instead:

```bash
g++ -std=c++17 -o /tmp/lab5-eligibility main.cpp && /tmp/lab5-eligibility
```

There are no external dependencies or required secrets.

`main.cpp` is the original assignment starter: the input prompts, eligibility checks, and messages are TODOs. It currently compiles but exits without output. Complete the exercise in `main.cpp`, then rerun the workflow. The README lists the sample inputs and expected behavior.
